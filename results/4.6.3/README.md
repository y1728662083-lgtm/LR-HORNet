# Section 4.6.3 results

`run_level_results.csv` contains 25 verified runs: five repeated fold-1 runs
for each of the 1-, 2-, 4-, 8-, and 16-group conditions.
`condition_summary.csv` is regenerated from those rows by
`../../figures/4.6.3/generate_result_tables.py`.

The source `test_metrics.json` and `training_log.csv` files are stored under
`../../experiments/4.6.3/reference_results/`.
