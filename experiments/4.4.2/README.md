# Section 4.4.2 protocol

This sweep fixes each test subject in turn and evaluates multiple choices of
validation subject. The base-training subjects are the subjects remaining
after the test and validation subjects are held out. Consequently, changing
the validation subject also changes the base-training composition. Results
from this section must be interpreted as sensitivity to the combined
validation-subject/training-composition condition, not as an isolated effect
of validation-subject identity.
