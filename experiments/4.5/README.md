# Section 4.5 protocol

The reported progressive comparison contains five stages. The first four are
trained by this section's runner. The final LR-HORNet stage reuses the complete
ds003626 ten-fold main experiment from Section 4.4.1 to avoid duplicate
training cost. The released `reference_results/lr_hornet_main/` files are the
same source metrics and training logs used by the Section 4.4.1 result table.

By default, `run_4_5.sh` trains only the first four stages. The complete model
remains an explicit `--models group4_patchLstm_deformableLstm` option for users
who want to rerun it. The publication table and figure are regenerated by
`figures/4.5/generate_result_tables.py`, which verifies the reused hashes and
fold metrics against the Section 4.4.1 source table.
