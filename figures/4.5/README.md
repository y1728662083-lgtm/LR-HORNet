# Section 4.5 figure provenance

Run `python plot_progressive_ablation.py` to validate the 50 released fold
records, regenerate both CSV tables, verify the final LR-HORNet stage against
the Section 4.4.1 main-result hashes and metrics, and export the PNG and SVG
figures. The final stage has mean test accuracy 30.90%; it is a documented
reuse of the main experiment rather than a separately trained ablation run.
